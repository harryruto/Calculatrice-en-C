# BUG REPORT

## 🇫🇷 Français

### Signaler un bug

Si vous trouvez un bug dans **Calculator**, merci de le signaler afin qu’il puisse être analysé et éventuellement corrigé.

Avant de créer un rapport :

* Vérifiez qu’un rapport similaire n’existe pas déjà.
* Vérifiez que le problème concerne bien Calculator.
* Utilisez une version récente du logiciel lorsque cela est possible.

### Informations à fournir

Un rapport de bug doit contenir autant que possible :

* **Titre :** description courte du problème.
* **Version :** version de Calculator utilisée.
* **Système :** système d’exploitation utilisé.
* **Description :** expliquez clairement le problème.
* **Étapes pour reproduire :**

  1. Lancez Calculator.
  2. Effectuez l'opération concernée.
  3. Indiquez les actions qui provoquent le problème.
* **Résultat attendu :** ce qui aurait dû se produire.
* **Résultat obtenu :** ce qui s’est réellement produit.
* **Message d’erreur :** s’il y en a un.
* **Logs :** ajoutez les informations pertinentes provenant de `log.logfile` ou `error.logfile` si elles sont disponibles.

### Exemple

```text
Titre : Erreur lors d'une opération

Version : 3.0
Système : Windows

Description :
Une erreur apparaît lorsque j'effectue cette opération.

Étapes pour reproduire :
1. Lancer Calculator.
2. Sélectionner l'opération concernée.
3. Entrer les valeurs utilisées.

Résultat attendu :
Le résultat correct devrait être affiché.

Résultat obtenu :
Le programme affiche une erreur.

Message d'erreur :
[Message éventuel]

Logs :
[Informations pertinentes]
```

### Bugs de sécurité

Si le problème peut avoir un impact sur la sécurité du logiciel ou de l'utilisateur, **ne publiez pas d'informations sensibles publiquement**.

Contactez directement le mainteneur du projet :

**Harryruto — Queris Studio**

Pour les autres problèmes, utilisez le système de signalement prévu par le dépôt.

## 🇬🇧 English

### Reporting a Bug

If you find a bug in **Calculator**, please report it so it can be investigated and potentially fixed.

Before creating a report:

* Check whether a similar report already exists.
* Make sure the problem is related to Calculator.
* Use a recent version of the software when possible.

### Information to Provide

A bug report should contain, whenever possible:

* **Title:** short description of the problem.
* **Version:** Calculator version being used.
* **System:** operating system being used.
* **Description:** clearly explain the problem.
* **Steps to reproduce:**

  1. Launch Calculator.
  2. Perform the affected operation.
  3. Describe the actions that cause the problem.
* **Expected result:** what should have happened.
* **Actual result:** what actually happened.
* **Error message:** if there is one.
* **Logs:** include relevant information from `log.logfile` or `error.logfile` if available.

### Example

```text
Title: Error during an operation

Version: 3.0
System: Windows

Description:
An error occurs when performing this operation.

Steps to reproduce:
1. Launch Calculator.
2. Select the affected operation.
3. Enter the values used.

Expected result:
The correct result should be displayed.

Actual result:
The program displays an error.

Error message:
[Possible error message]

Logs:
[Relevant information]
```

### Security Bugs

If the issue may have an impact on the security of the software or the user, **do not publicly disclose sensitive information**.

Contact the project maintainer directly:

**Harryruto — Queris Studio**

For other issues, use the reporting system provided by the repository.
